# Interaction Wireframe Pack v0.2 — Monster Night Bus
Whole-MVP coverage: Night Route Brief, Bus Route Gameplay, Run Result; Stop Service, Travel, Travel Warning, Pause, success/failure Result; all five traits, route reachability, Large reservation, WetResidue, both forbidden-pair warnings, boarding/unboarding/re-seat, arrival/disembark and retry. Core gameplay uses six explicit seat targets and two standing targets, a route selector, waiting queue, Comfort/Score HUD and conflict countdown. All hard-invalid inputs reject without state mutation. Route choice is guarded by onboard destination reachability. Travel warnings expose exact pair and 2.0s deadline; arrival is held until warning queue clears. Content instances reuse PassengerCard/DropSlot/RouteNode templates while trait-specific state variants preserve every MVP interaction difference.
