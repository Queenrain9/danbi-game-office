# Pocket Ecosystem Smuggler — Interaction Wireframe Pack v0.3
Fun promise: 작은 가방 안의 먹이사슬을 예측·개입하면서 동시에 검문 흔적을 관리하는 압축된 생태 전략.

Flow: Run Setup → Suitcase Ecosystem → Checkpoint → Segment Result → next segment/restored retry → Run Result. Pause preserves state. Core play keeps the 3x3 suitcase dominant, exposes deterministic resolution and next-tick prediction, and makes checkpoint concealment a direct reading of the same ecosystem. Invalid input is non-destructive; failures restore the segment-start snapshot. Implementation architecture is intentionally deferred to Blueprint.
