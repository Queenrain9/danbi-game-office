# The Floor Is Yesterday — Interaction Wireframe Pack v0.3

## Fun Promise
지나온 공간의 지연된 과거 복원을 예측해 추격자의 길을 끊는 쾌감.

## Coverage
Stage Select, Stage Intro, Gameplay, Pause Overlay, Clear Result, Fail Result. Global/zone/pursuer states and corridor/door/platform/multi-timer variations are covered.

## Core Interaction
Movement arms delayed spatial restoration. Current topology, baseline ghost, fixed countdown, pursuer state and exit remain readable together. Rewind is automatic and never rewinds characters.

## Boundary
UX/state/data contract only; Godot architecture belongs to Implementation Blueprint.
