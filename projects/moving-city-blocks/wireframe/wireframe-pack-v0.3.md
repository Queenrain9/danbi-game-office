# Moving City Blocks — Interaction Wireframe Pack v0.3
Fun promise: 예측한 이동 순서가 도시의 도로·전력·서비스망을 실제로 끊고 다시 잇는 연쇄 결과를 읽는 재미.
Coverage: Session Select → Planning → Night Resolution → optional Repair → Day Result → next/retry → Session Result, with Pause.
Core: S2 Planning, S3 Resolution, S4 Repair. Planning keeps automatic tail visible and distinguishes current vs projected topology. Queue reordering uses semantic drag; grid inspection/repair remain explicit structured interactions.
