# Assembly Line Orchestra — Interaction Wireframe Pack v0.3

Mobile landscape. Core screen: Factory Setup/Edit. Five screens cover Select → Edit → Running ↔ Pause → Result with safe-stop recovery. The factory line is the primary visual object; beat timing is embedded in an 8-beat rail and machine motion rather than a separate rhythm lane. Drag placement is constrained to compatible sockets and invalid drops return to origin. Phase is 1–8 per module. Running forbids direct machine edits; Pause freezes simulation and Edit queues a stop at cycle boundary. Result preserves the 32-beat causal timeline and all rule-defined success/failure recovery. Variations: tutorial, single-route, branch-route, syncopated, mixed-processor. Fun promise: production optimization and rhythm composition must conflict and resolve through the same placement/timing decisions.
