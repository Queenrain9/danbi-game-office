# Playable Game Design Spec v0.1 — Deep Sea Cable Splicer\n\n## 1. Product Definition\n해저 케이블을 손으로 절개·배선·압착하는 portrait mobile repair puzzle, 4–6분. Non-goals: 선택지 게임, 경영, 실시간 액션.\n## 2. Player Fantasy\n심해 통신 수리기사로서 복잡한 신호 규칙을 읽고 죽은 회선을 살린다.\n## 3. Core Player Verbs\nStrip(drag), Route(drag/snap), Splice(hold clamp), Test(tap), Rework(long-press). 각 행동은 cable state/assignment/token을 변경한다.\n## 4. Core Loop\n확인→절개→4–6 fibers 배선→압착→test→오류 rework→복구. 3 jobs/session.\n## 5. Round / Session Structure\nSealed→Routing→ReadyTest→Rework(optional)→Result. 60–120초/job. Next/Retry.\n## 6. Game Rules\nRework 2. Strip corridor 20px; 150ms 이탈은 한 fiber attenuation +0.25. Bad pair는 signature mismatch. 2개 초과 crossing마다 attenuation +0.15. Signal >=0.8 pass. Failed channel은 waveform으로 특정. Unlock 완료 시 token -1. Token 0에서 재실패하면 terminal fail. Retry full reset.\n## 7. State Model\nSealed(strip), Routing(route/snap/clamp), ReadyTest(test), Rework(unlock/reroute), Result(next/retry). Pause 시 모든 timers/animation simulation 정지.\n## 8. Interaction Spec\nStrip은 seam corridor forward drag. Lift는 pause. Fiber는 empty slot 24px snap; occupied rejects and returns. Clamp hold 400ms locks. Dragged fiber pointer priority. Test는 required pairs locked 전 disabled. Rework long-press 300ms.\n## 9. Content Model\nJob = fiber count×signature mapping×crossing constraint×damage×slot order. MVP 3 authored jobs.\n## 10. Difficulty / Variation\n4 direct color→4 symbol remap→6 crossing-sensitive. Speed-only scaling 없음.\n## 11. Progression\n3 jobs sequential unlock+best grade.\n## 12. Economy\nNot required.\n## 13. Screen Inventory\nJob Select, Splice Workbench, Job Result.\n## 14. Screen Flow\nSelect→Strip→Routing→Test→Pass Result 또는 Rework→Test; tokens 0 fail→Result; Retry full reset.\n## 15. Feedback System\nSheath peel/damage tick, slot glow/snap, clamp pulse, waveform sweep, failed-channel isolation, clean signal success.\n## 16. Visual Direction Brief\nPortrait close-up workbench, dark deep-sea hardware vs luminous fibers, thick readable endpoints/slots, diagnostic waveform without layout prescription.\n## 17. MVP Scope\n3 jobs: 4 direct, 4 remap, 6 crossing. Strip damage, route/snap, clamp, test, 2 tokens, result/retry. NOT IN MVP: procedural, economy, upgrades, narrative, >6 fibers, timed mode.\n## 18. Test Scenarios\nAll jobs complete; invalid slot always returns; failed test identifies channel; token/terminal fail consistent; pause/retry deterministic.\n## 19. Known Risks\nOcclusion, color accessibility, crossing mismatch, repetitive stripping.\n## 20. Wireframe Handoff\nShow all screens/states, strip damage/cancel, route snap/reject, clamp/test lock, waveform diagnosis, token use, terminal fail, full retry reset. No game-rule invention required.
