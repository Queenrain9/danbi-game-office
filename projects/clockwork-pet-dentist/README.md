# Clockwork Pet Dentist

This folder is the durable production archive for this game.

- Game Design: `game-design/`
- Interaction Wireframe Pack: `wireframe/`
- Implementation Contract / Fidelity Blueprint: `implementation/`
- Final Godot build archive: `build/`
- Fidelity evidence/reviews: `fidelity/`
- Playtest showroom: `playtest/`
- Visual development: `visual/`

Live queue/status data stays in Supabase. `manifest.json` links that operational state to this durable GitHub archive.
