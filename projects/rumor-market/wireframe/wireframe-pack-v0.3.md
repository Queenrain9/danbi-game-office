# Rumor Market — Interaction Wireframe Pack v0.3

Portrait whole-MVP pack covering all 9 inventory screens and 7 states. Fun promise: 한 사람에게 흘린 소문의 결정론적 관계망 파장을 예측하고, 때로 한 번 뒤집히는 정보가 가격·행동·관계를 바꾸는 결과를 이용하는 재미.

Core UX exposes topology and acceptance inputs before the single daily seed, then renders deterministic propagation in causal order. Early sparse and later dense/rival scenarios reuse the same rules. Implementation architecture is intentionally deferred to Implementation Blueprint.
