# Night Signal Operator — Playable Game Design Spec v0.1
## 1. Product Definition
Portrait mobile signal puzzle, 4–6분. 렌즈·필터·셔터 직접 조작. 사실적 항해·경영은 Non-goal.
## 2. Player Fantasy
빛만으로 배를 안전하게 이끄는 신호소 운영자.
## 3. Core Player Verbs
Lens rotate, filter slide, shutter press/release, vessel select, send.
## 4. Core Loop
요청→선택→방향/색→펄스→송신→항로 반응.
## 5. Round / Session Structure
5척, 4–6분, 3 strikes/deadline miss 실패.
## 6. Game Rules
8방향, 3색, short/long timing, 1–4 pulses, deadlines, streak.
## 7. State Model
brief→compose↔transmit→evaluating→warning/result.
## 8. Interaction Spec
Circular drag snap, filter snap, shutter press/release, Send precondition.
## 9. Content Model
Vessel/sector/color/code/deadline/queue/visibility.
## 10. Difficulty / Variation
단일 2펄스→방향 결합→동시 큐/3–4펄스/시야 제약.
## 11. Progression
3 기본 규칙 후 Mixed Shift.
## 12. Economy
Not required.
## 13. Screen Inventory
Shift Select, Rule Brief, Signal Station, Pause, Result.
## 14. Screen Flow
Select→Brief→Station loop→Result.
## 15. Feedback System
Beam, color, timeline, detents, answer lamp/path, warning haptic.
## 16. Visual Direction Brief
상단 바다, 하단 큰 장치, 높은 기능 대비.
## 17. MVP Scope
5 ships, 3 rules, 8 requests, actual gestures/timing/evaluation/path response. Final art/economy 제외.
## 18. Test Scenarios
8방향, duration 판정, wrong reject, path response, 동시 2척.
## 19. Known Risks
Timing fairness, readability, rote memory, overload.
## 20. Wireframe Handoff
모든 screen/state variant와 wheel/filter/shutter/send/target/deadline feedback을 표현.
