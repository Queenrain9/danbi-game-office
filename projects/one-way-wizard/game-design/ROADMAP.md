# One-Way Wizard — ROADMAP v0.2

## First Build candidate

Validate the central persistence fantasy before broadening content:
- one arena,
- persistent toroidal Bolt trajectories,
- cap/lifetime/mana,
- Redirect and Split on existing projectiles,
- deterministic fixed-step rule clock,
- a short pressure sequence with Chaser/Drifter,
- a minimal Carry-style continuation only if needed for the core persistence question.

The first playable must test whether old projectiles are readable tactical assets rather than visual noise.

## Second Build

Add all three wave rosters, Anchor hazards, full Carry Select, three arena variants, scoring and run result. Re-test cast-only dominance versus Redirect/Split/Merge-assisted play.

## Third Build

Tune control feel, trail density, merge tolerance, edge-pair cues, haptics/audio and accessibility from human playtest evidence.

## Later / Optional

Deckbuilding, elemental systems, bosses, >8 projectiles, projectile-wall reflection, procedural generation, permanent stat upgrades, economy and online modes remain outside the validated MVP.
