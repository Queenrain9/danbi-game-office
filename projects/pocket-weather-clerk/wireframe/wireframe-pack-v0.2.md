# Pocket Weather Clerk — Interaction Wireframe Pack v0.2
Core: Weather Desk. Portrait mobile, 0–100 coordinates, direct-manipulation first. Six inventory surfaces are represented: Shift Board, Order Brief, Weather Desk, Pause Overlay, Order Result, Shift Complete. Weather Desk exposes target strip, adjustment counter, cloud hit area, town feedback, wind rotary, humidity valve, Observe, Submit and settle progress. Gesture ownership is single-pointer; continuous motion commits once on release. Adjusting → settling → adjusting is the main micro-loop; Submit enters evaluating and then Result. Invalid/locked inputs never mutate game state. Data is five weather orders. Godot ownership: AppRoot for shift progression; WeatherSession for order variables/rules; UI is presentation. Acceptance requires complete five-order replay loop, no stale state, and all three gestures affecting the same state evaluated at result.
