# Pocket Canal Keeper — Interaction Wireframe Pack v0.2
Core: Canal Board. Portrait fixed oblique board with the whole canal graph readable while devices are manipulated. Six inventory surfaces are represented: Stage Select, Stage Brief, Canal Board, Boat Inspect Popover, Pause Overlay, Stage Result. Core controls are gate arc drag, bridge circular drag, lock vertical drag, signal tap and boat inspect. Protected-segment occupancy is atomic and unsafe commands are rejected before state corruption. Device Busy is a board variant, not a new screen; independent devices remain usable. Warning highlights only the affected protected zone. Boat inspection is non-destructive and simulation continues. Godot ownership: AppRoot progression, CanalSimulation graph/boats/devices/timers, UI presentation. Six data-driven stages and complete retry/next/unlock loop are required.
