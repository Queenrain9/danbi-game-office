# Living Game v0.2 — Crystallization Prototype

v0.1의 선택지형 진단을 폐기하고, 사용자가 먼저 놀면 시스템이 다음 실험을 매번 다시 결정하는 구조로 바꾼 프로토타입이다.

## 핵심 원칙

- 시작은 점 하나다.
- 사용자는 장르/취향 질문에 답하지 않는다.
- 이동량, 속도, 정지, 가장자리 탐색, 반복 접근, 수집, 동행 유지, 회피 등을 관찰한다.
- 매 단계의 다음 실험은 현재까지의 행동을 보고 런타임 정책이 다시 결정한다.
- 일정 시간 뒤 시스템이 게임 하나를 확정한다.
- 사용자가 고르는 것은 게임 후보가 아니라 **같은 게임의 Art Direction 3안**뿐이다.
- Art Direction을 골라도 게임 룰은 바뀌지 않는다.
- 선택 뒤 즉시 실제 플레이 가능한 미니게임으로 이어진다.
- 확정된 게임은 내 게임팩에 저장된다.

## v0.2에서 구현한 세로 슬라이스

점 하나 → 행동 관찰 → 동적 실험 생성 → Game Design Lock → Art Direction 3안 → Art DNA 선택 → 즉시 플레이 → Game Pack 저장

현재 'AI' 부분은 실제 LLM이 아니라 행동 점수 + 상황 기반 정책으로 구현되어 있다. 목적은 생성 모델을 붙이기 전에 **상호작용 구조 자체가 재미있는지** 검증하는 것이다.

4. 확정 Game Design을 Game Genome schema로 검증
